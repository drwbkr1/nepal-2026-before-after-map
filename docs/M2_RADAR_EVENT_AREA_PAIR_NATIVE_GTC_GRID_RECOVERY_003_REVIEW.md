## Why this method is being considered

The prior M1-SRC-002 attempt is consumed and indeterminate. Its saved GTC outputs report EPSG:4326, 2 × 2 cells at 10 degrees per cell, despite fine-grid slant inputs and a one-arc-second DEM mosaic. The existing code supplied a projected 10 m snap raster and numeric `cellSize=10.0` around native GTC. The numeric match is a plausible unit-interaction lead, **not an established cause**. The GTC configuration identity remains unresolved. Two subsequent projection/clip candidates failed on disposable inputs and did not start a new real attempt.
