## What this would solve

The project has an editable EPSG:32645 ArcGIS metadata workspace, but no real before/after pair has passed usable-pixel and registration QA. The local ArcGIS radar GTC attempts are terminal without a valid projected pair, and the assessed optical pairs are blocked. ASF's HyP3 Basic can generate full-scene GAMMA RTC UTM GeoTIFFs from Sentinel-1 IW GRD-H scenes, including VV/VH and a layover/shadow raster. This is a **new processed source and method** that could supply inspectable ArcGIS map inputs; it cannot be labeled a successful continuation of the prior local processing. ## Recommended exact route

The [exact proposal](../contracts/milestone-002-asf-hyp3-rtc-map-route-001-proposal.json) names the same four source IDs as the frozen ascending radar pair plan: 16 August M1-SRC-001/002 before and 28 August M1-SRC-004/005 after. All four exact Sentinel-1D GRD names returned public ASF catalog rows. The event-area pair M1-SRC-002/005 had 100% *catalog* overlap of the source and upper-corridor AOIs, but only 96.999% of the overview AOI; the adjacent M1-SRC-001/004 pair covers a different roughly 2.994% overview strip. A [new union-by-date calculation](../records/observations/m2-asf-four-source-catalog-mosaic-coverage-001-local.json) places all four catalog footprints at **99.993% both-date overview overlap** and 100% for both event AOIs. This clears the frozen 99% threshold as a **catalog screen**, not as provider output or usable RTC pixels. [Pair triage](../records/observations/m2-radar-event-pair-catalog-triage-001.json) · [ASF observations](M2_ASF_HYP3_MAP_ROUTE_PREPARATION_001_LOCAL.md)

The [offline candidate](../records/observations/m2-asf-rtc-four-scene-candidate-001-local.json) proposes one 10 m `RTC_GAMMA` job per exact scene, in event-first order **002, 005, 001, 004**, with Copernicus DEM, gamma0 **power** output, no provider speckle filter or DEM matching, and the optional DEM/incidence/scattering-area files included. This is separate from the earlier unapproved two-scene dB candidate. HyP3 GAMMA, its DEM and orbit use, and its mask codes must be recorded as their own provenance; the project's local AUX_RESORB files and `REFINED_LEE` cannot be claimed as used by ASF.
